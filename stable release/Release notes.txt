<h2>What's new in OpenTTD Archipelago 1.4.1</h2>
<hr>

<h3>Release Overview</h3>

<p>
<strong>OpenTTD Archipelago 1.4.1</strong> is a bugfix release that fixes bridge unlock behaviour, star check delivery, and star counter display.
</p>

<ul>
<li>Fix: <strong>Bridge button unlock</strong> — the bridge toolbar button now unlocks as soon as you receive your first bridge item. Previously it stayed locked until all 13 bridge types were unlocked.</li>
</ul>

<hr>

<h3>Compatibility</h3>

<ul>
<li>This version is <strong>compatible with multiworld sessions created using version 1.4.0+</strong>.</li>
<li>The APWorld file remains <code>openttd.apworld</code> (stable) / <code>openttd_exp.apworld</code> (experimental).</li>
</ul>

<hr>

<h3>Requirements</h3>

<ul>
<li>Windows 10 / 11 (64-bit) or Linux x64</li>
<li>Archipelago 0.6.6+</li>
<li>Python 3.10+ (for APWorld generation only)</li>
</ul>
